# 📊 Excel Analysis

This folder documents the Excel-first approach used for the PhonePe UPI Transactions project.

## Approach

The project was developed using **Microsoft Excel without Power Query**.

The objective was to demonstrate that useful operational analysis and a management-friendly dashboard can be created directly in Excel from transaction data.

## Analytical Areas

- Transaction KPIs
- Success-rate monitoring
- Transaction category analysis
- State-level analysis
- Bank/app comparison
- Hour-wise analysis
- Day × hour pattern analysis
- Exception/fraud indicator analysis
- Dashboard reporting

## Recruiter Perspective

This project is intentionally different from a Power BI-only portfolio project. It demonstrates practical **Excel reporting and MIS-style analysis**, which is highly relevant for entry-level reporting and MIS roles.
